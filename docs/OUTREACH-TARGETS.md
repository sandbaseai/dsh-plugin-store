## Personalized message

Hi, I found **[repository]** in the DeepSeek Harness community catalog under **[category]**.

We are building an open-source native Store for DSH with Community and Installed views, server-side tag filters, local profile installation, and Agent catalog tools.

Your plugin is a useful test case because **[specific reason]**. Would you be willing to check whether its listing and install path look correct? If the direction is useful, a Star or one piece of feedback would help us prioritize the upstream integration.

https://github.com/sandbaseai/dsh-plugin-store

## Follow-up rule

Send at most one follow-up after five days. Include a concrete improvement made from another author's feedback. Do not send a generic reminder.
