# Contributing

Thanks for helping improve DSH Plugin Store.

## Useful contributions

- Report catalog entries that fail to install
- Propose UI improvements for Community or Installed views
- Test against a recent DeepSeek Harness source checkout
- Document private catalog, allowlist, and audit requirements
- Share a plugin that should be easier to discover

## Issues

When reporting a problem, include:

- DeepSeek Harness version or commit
- Node.js and pnpm versions
- Operating system
- Plugin repository or catalog category
- Exact error output with secrets removed

## Security

Do not publish credentials, internal repository URLs, or sensitive logs in a public issue. For a vulnerability that could affect plugin installation or repository validation, contact the maintainers privately before disclosure.
